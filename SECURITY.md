# Security and privacy

This app reads local files and never needs administrator access. Keep generated `output/` private. It includes a copy of the selected save. Do not disable security software to run this program; inspect the source or run the Python source if you do not trust an unsigned executable.

Please do not publish sensitive files in an issue. For a security concern, initially report only a non-sensitive summary and ask for a private reporting route. The HTML app uses no telemetry or backend. Loading the optional external map sends normal web requests to its provider, without save contents.
